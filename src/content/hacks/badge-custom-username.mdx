Use the **Settings** app to configure the badge without writing code. It stores your Wi-Fi connection, GitHub username, contact card, and display brightness.

The available settings are:

| Setting | What it controls |
| --- | --- |
| **WiFi Network** | The 2.4 GHz network used by online apps |
| **WiFi Password** | The password for that network |
| **GitHub Username** | Your avatar, profile, contribution graph, and GitHub contact link |
| **Contact Name** | The name shown when you share contact details |
| **LinkedIn Profile** | Your LinkedIn username or full profile URL |
| **Backlight** | The display brightness |

## Prerequisites

- The settings you want to add. You can leave fields you do not use empty.
- A 2.4 GHz Wi-Fi network for online apps (see [Wi-Fi](#wi-fi) below)
- For the USB method: a USB-C data cable and [VS Code](https://code.visualstudio.com/) or any text editor

## Option 1: Use the Settings app

1. Open **Settings** from the menu.
2. Use **Up** and **Down** to move through the settings.

   <img src={sitePath('/images/hacks/github-handle/settings-list.png')} alt="Settings app with the GitHub Username row highlighted" />

3. To change **WiFi Network**, **WiFi Password**, **GitHub Username**, **Contact Name**, or **LinkedIn Profile**, highlight the field and press **Select** (the white circle).
4. Type the value on the on-screen keyboard. Move with the direction pad and press **Select** to type the highlighted key. **Back** deletes a character, `shift` switches case, and `#+=` shows symbols.

   <img src={sitePath('/images/hacks/github-handle/settings-keyboard.png')} alt="On-screen keyboard typing a GitHub username" />

5. Highlight **done** and press **Select**. The hint changes to **saved!**

   <img src={sitePath('/images/hacks/github-handle/settings-saved.png')} alt="Settings app showing the saved GitHub username" />

6. Repeat those steps for each text field you want to configure:
   - Enter the Wi-Fi network name and password exactly, including capital letters.
   - Enter only your GitHub username, without `@` or `github.com/`.
   - Enter the name you want other badge owners to receive.
   - Enter either your LinkedIn username or a full `linkedin.com/in/...` profile URL.
7. Highlight **Backlight**, then press **Left** or **Right** to change the brightness in 10% steps. The badge saves the new level automatically.
8. Press **Back** to leave Settings.

The screenshots show the GitHub username workflow, but the same keyboard and save controls apply to every text field.

## Option 2: Edit `secrets.py` in VS Code

1. **Connect the badge to your computer** with a USB-C data cable.
2. **Enter USB mode.** Double-tap the badge's reset button, or open the **Mass Storage** app from the menu. The screen shows **USB Disk Mode** and a drive named **BADGER** appears on your computer.
3. **Open the drive in VS Code.** Choose `File → Open Folder...` and select **BADGER**.
4. **Edit `secrets.py`** at the root of the drive:
   ```python
   WIFI_SSID = "HYB-26"
   WIFI_PASSWORD = "..."
   GITHUB_USERNAME = "your-handle"
   CONTACT_NAME = "Your Name"
   CONTACT_LINKEDIN = "your-linkedin-handle"
   REGION = "us"  # Options are us, cuba, eu, moldova, lebanon, egypt, chile, australia, nz
   TIMEZONE = -7  # Offset from GMT as number of hours, i.e. 0, 1, -7 etc.
   ```
   Keep the quotes, and leave any text setting you do not use as `""`. `REGION` and `TIMEZONE` are additional computer-edited settings used by apps such as Clock. Change the backlight from the Settings app.
5. **Save the file and eject BADGER** (Finder: click ⏏; Windows: **Safely Remove Hardware**). The badge restarts automatically. If it doesn't, press reset once.

Values you set in `secrets.py` take priority over the Settings app. Settings shows those fields with a padlock and **locked**. To edit them on the badge again, set them back to `""` in `secrets.py`.

<img src={sitePath('/images/hacks/github-handle/settings-locked.png')} alt="Settings app showing a locked GitHub username set in secrets.py" />

## Wi-Fi

Your badge comes set up for the **HYB-26** network in the **Hack Your Badge** area. The badge only supports **2.4 GHz** Wi-Fi, so it can't join the main conference network, which prefers 5 GHz. To use your home Wi-Fi or your phone's hotspot, see <a href={sitePath('/hack/connect-wifi/')}>Connect to Wi-Fi</a>.

## Verify

- Open the **Badge** app. Your GitHub profile and contribution graph should load after Wi-Fi connects.
- Open **Contacts** and check that your name, GitHub username, and LinkedIn profile appear on your contact card.
- Return to **Settings** and confirm the backlight remains at the selected level.
- If an online app reports a connection error, check the network name and password and confirm the network uses 2.4 GHz.

## Safety tips

- `secrets.py` is plain text and includes your Wi-Fi password. Don't commit your copy to Git.
- Always eject **BADGER** before unplugging the badge or pressing reset, so your changes are saved.
