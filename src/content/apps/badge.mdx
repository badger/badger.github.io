## Features

- GitHub contribution graph, avatar, and username
- Followers, public repositories, and contributions
- Offline cache after the first sync
- Hold A+C to refresh

## Configuration

Set these values in `/secrets.py`:

```python
WIFI_SSID = "network-name"
WIFI_PASSWORD = "network-password"
GITHUB_USERNAME = "github-handle"
```
