# Build with VS Code

Describe your idea in Copilot Chat. Copilot builds the app and copies it to
your connected badge. You test it on the badge.

These steps work on Windows and macOS. They assume VS Code, GitHub Copilot,
Python 3.10 or newer, and `hyb26-skill` are already installed. The skill is
a set of instructions and tools that helps Copilot build apps for this badge.
Installation is not covered here. You do not need to write code yourself.

<ConnectBadge />

## 2. Open Copilot Chat in VS Code

1. Open **VS Code** and use the **Badge Projects** folder prepared for you.
2. Open **Copilot Chat**. On **Windows**, press **Ctrl + Alt + I**.
   On **macOS**, press **Control + Command + I**.
3. Start a new chat and select **Agent** so Copilot can create files and run
   the badge tools. Work locally on your computer, not in a cloud session.

If no folder is open, choose **File > Open Folder** and select **Badge
Projects** in Documents. If it is missing, ask a volunteer for help.
This folder is just a place to save your work. Copilot creates the app
files inside it. You do not need a repository.
