# Build with the GitHub Copilot App

Describe your idea in the GitHub Copilot desktop app. Copilot builds the
app and copies it to your connected badge. You test it on the badge.

These steps work on Windows and macOS. They assume the GitHub Copilot App,
Python 3.10 or newer, and `hyb26-skill` are already installed. The skill is
a set of instructions and tools that helps Copilot build apps for this badge.
Installation is not covered here. Use the **GitHub Copilot** app, not
Microsoft Copilot. You do not need to write code yourself.

<ConnectBadge />

## 2. Open a local project in the Copilot App

1. Open the **GitHub Copilot App**.
2. Under **Projects**, select the **Badge Projects** folder prepared for you.
3. Start an **Interactive** session for that local project.

Use a local session on your computer, not a cloud session. A cloud session cannot
access the badge plugged into your computer. Use the project session, not a
general chat, so Copilot has a place to save your app.
