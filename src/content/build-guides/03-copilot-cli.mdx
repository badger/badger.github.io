# Build with GitHub Copilot CLI

Copilot CLI is Copilot in a terminal: a window where you type messages and
commands. Describe your idea in plain language. Copilot builds the app and
copies it to your connected badge. You test it on the badge.

These steps work on Windows and macOS. They assume GitHub Copilot CLI,
Python 3.10 or newer, and `hyb26-skill` are already installed. The skill is
a set of instructions and tools that helps Copilot build apps for this badge.
Installation is not covered here. You do not need to write code yourself.

## 2. Open the prepared Copilot CLI session

1. Open the **Copilot CLI** terminal prepared for you in the local **Badge
   Projects** folder.
2. If Copilot asks you to trust the folder,
   confirm it is the local **Badge Projects** folder before accepting.
3. Use the local session on your computer. Do not send the task to a cloud agent,
   which cannot access the connected badge.

If no session is ready, find **Badge Projects** in Documents. If it is missing,
ask a volunteer for help.

**Windows:** open the folder in File Explorer, right-click an empty space,
and choose **Open in Terminal**. In PowerShell, type `copilot` and press
**Enter**.

**macOS:** open **Terminal** from **Applications > Utilities**. Type `cd`
followed by a space, then drag **Badge Projects** from Finder into Terminal.
Press **Return**, then type `copilot` and press **Return** again.

If the command is not found, ask a volunteer for help.

You do not need a repository or any other setup commands. Once Copilot is
running, type your request as a chat message, not as a terminal command.
